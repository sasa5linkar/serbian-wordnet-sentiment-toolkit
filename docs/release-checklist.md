# Release checklist

- Tests, Ruff, mypy, and package build pass.
- Wheel installs and CLI smoke tests pass in a clean environment.
- README commands are verified.
- Audit finds no secrets, paths, annotations, outputs, environments, or models.
- Resource provenance and redistribution are documented.
- Citation and thesis status are current.
- Human review approves claims and licenses.
- Public visibility and v0.1.0 wait until all checks pass.
